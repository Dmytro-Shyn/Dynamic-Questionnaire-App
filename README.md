# Dynamic Questionnaire App

A React + TypeScript questionnaire application with dynamic question flow and Algolia-powered results.

## Status

Project scaffold is initialized (Step 1). Detailed setup instructions, architecture notes and AI-friendly documentation will be added as the project progresses.

## Tech Stack

- **Vite** + **React 19** + **TypeScript**
- **Redux Toolkit** & **react-redux**
- **TailwindCSS v4** + **shadcn/ui**
- **Algolia** (search client)
- **ESLint** + **Prettier**

## Local Setup

```bash
npm install
npm run dev
```

## Scripts

| Script           | Description                         |
| ---------------- | ----------------------------------- |
| `npm run dev`    | Start the Vite dev server           |
| `npm run build`  | Type-check and build for production |
| `npm run lint`   | Run ESLint                          |
| `npm run format` | Format all files with Prettier      |
